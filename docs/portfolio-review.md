Keep the existing dark, cinematic design and domain. Reorder the portfolio around **animation, drawing and visual storytelling**, with film as a complementary strength. The site already has useful foundations; it needs clearer priorities and more specific evidence, rather than a complete redesign.

## 3. Assessment of the new drawings

The collection shows enthusiasm for action staging, costume, muscular forms, foreshortening and dramatic viewpoints. The most readable ink pieces use black shapes effectively. More complex scenes show ambition but sometimes lose the focal point among equally strong outlines, motion marks and anatomy detail.

For an animation portfolio, supplement these with readable gestures, expression changes, everyday observation and short sequences. Static action drawings support an animation application, but they cannot demonstrate timing or spacing on their own. The existing observational sketchbook helps balance the genre-heavy selection.

### AI correction: conclusion with the originals now available

02 does not immediately look AI-generated. Comparing it with 18 shows that the unusual right-side hand, sword and broad motion band were already present in the original drawing. Those details are not evidence of AI invention. The corrected version is flatter, brighter and more strongly defined, but different perspective/lighting prevent a reliable stroke-by-stroke conclusion from this comparison alone.

01 and 05 also appear to show the same underlying composition. Treat them as alternate captures/processed versions until Josh confirms the history.

Use the physical artwork as the reference. Prefer a flatbed scan, or a photograph taken square-on in soft, even light. Correct rotation, perspective, exposure and white balance conservatively. Preserve faint pencil marks and the whole intended composition. Do not regenerate hands, anatomy, ink lines or missing edges. Keep the unmodified source privately.

“Photograph adjusted for lighting and colour” is accurate only when that is what happened. If AI altered the drawing, a fresh faithful capture is the better default for demonstrating drawing ability. This guide does not assume how the existing site's cleanup examples were made.

## 4. Present projects, not just pictures

For a selected animation: descriptive title, playable clip, duration if measured, Josh's confirmed role, actual tools, what he explored, and authentic roughs/key poses if available. Label a motion-comic or animated illustration accurately where only selected elements move; do not automatically relabel all work as full character animation.

For drawing: short title, confirmed medium, original/fan art/reference-study classification, one sentence about the visible work and optional genuine development material. Reference studies are legitimate learning evidence; name the source artist when known. Depicting a known character is different from independently designing that character.

For film: one selected reel and 2–3 selected projects, exact role and credits, plus a brief note on framing, editing or sound where Josh can substantiate it. Keep live-action footage out of an animation-specific reel. The existing mixed creative reel can remain as a separately labelled broader introduction.

A useful next project would be a short sequence: thumbnails → 6–12 storyboard panels → rough animatic → a brief animated shot. It would connect Josh's drawing and film interests. This is future work, not content the website agent should fabricate.

## 5. How to run the VS Code prompts

1. Open the existing website repository in VS Code.
2. Save this guide as `docs/portfolio-review.md` in that repository.
3. Copy the 20 original uploads into a private project folder such as `portfolio-incoming/`. Keep that folder out of the site's public directory and deployment output. Do not commit it automatically.
4. Run the prompts below one at a time in your coding assistant's agent mode. Let each stage finish and inspect the local preview before continuing.
5. Confirm artwork sources and choose the final animation/film examples with Josh. Drafts needing factual confirmation should remain unpublished, while other improvements proceed.

The prompts are framework-neutral because this review did not inspect the source repository. They explicitly ask the agent to discover and reuse the existing implementation.
